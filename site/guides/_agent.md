## If you are an AI agent

Follow these rules when a person asks you to do this guide for them:

1. Tell the person what you will make. Ask before you make each thing.
2. The person signs in. Never ask for their password.
3. If you control a browser, the person watches. Stop at the screen that shows the key. Let the person copy it, or put it straight into `.env` without showing it.
4. Never show a key in the chat, a log, or a screenshot.
5. Before you save a key, make sure `.env` is listed in `.gitignore`. If it is not, add it.
6. Run the check in *Check it works*. Report *it works* or the error. Never report the key.
