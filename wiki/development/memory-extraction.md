# Experimental memory extraction

Experimental extraction returns bounded original facts for a standalone question through the [memory interface](memory.md).

`extract` is opt-in experimental work; routine search, briefs, and startup hooks retain their model-free behavior. Obtain a handle with `memory.mjs extract-task [scope filters]`, then call `memory.mjs extract "standalone question" --task <handle> --agent claude [same filters]`. Reuse that handle for the same task; it expires after twenty-four hours. Handles are tied to the repository, installation ID, caller credential fingerprint, and exact scope. Author labels do not change the handle. Changed credentials or filters require explicit creation of a new handle. Do not pass the parent conversation.

Each handle allows **12,288 UTF-8 bytes supplied to the model, 3,072 bytes returned, three candidate searches, and two model calls** in total, including repeated rounds and fallback/status output. Concurrent requests serialize reservations. Each request has a twenty-second deadline, with time reserved for final verification. Fixed status and evidence metadata consume output allowance; whole fact bodies are never cut. An exhausted output allowance returns no additional packet and exit code 3. Missing, expired, or mismatched handles fail without a packet. A crashed request may leave a locked handle; it never silently resets allowances.

The caller explicitly names its host with `--agent`. Claude runs in a temporary folder with safe mode, no built-in/MCP tools, skills, repository instructions, hooks, or saved session. It retains existing host authentication and model selection; `--model` explicitly chooses a model. Managed-policy configurations that cannot establish isolation are unsupported. Codex currently has no verified tool-free adapter, so a Codex caller receives a visible deterministic fallback; it is never silently switched to Claude. The Claude adapter caps completion output at 2,048 tokens and disables host API retries. These limits do not establish actual cost or retrieval quality.

Each candidate query has a hard twenty-row SQL limit and admits at most 4,096 bytes of whole records. `--all` and `--state` are rejected on extract: state filtering's inherited all-rows scan cannot meet this contract. Ordinary search and briefs keep their existing filters. Alternative search terms cannot change the original scope. The model can only select supplied IDs, propose two short queries, and return fixed gap codes. Code re-reads selected IDs in one permission-enforced batch before returning original facts with dates, authors and source pointers. Replaced or inaccessible evidence is excluded. Verification failure returns unavailable or denied without cached facts. Extract never reads transcripts or writes stored facts.

Packets report selected, partial, fallback, empty, unavailable, or denied, and explicit gaps. Limits and fallback never imply complete recall. `--loaded 7,8` omits already supplied IDs; returned IDs are also deduplicated across that handle. Use `source` separately when evidence needs checking. `--usage-report` saves a private body-free report under the local memory state's `extract-reports/`: application input/output bytes, model identity, model launches, store requests including probes/verification, wall time, and provider-reported input/output/cache tokens or unknown usage. Reports do not enter the fact packet. The allowance covers new helper-interface context; provider instructions, internal reasoning, ordinary reads, the digest, and the main conversation remain separate. A smaller returned packet can require more total model usage and waiting.

The source repo's `node scripts/evaluate-memory-search.mjs --context --json` compares eight- and twenty-fact selections with an explicitly labeled deterministic fallback, under the same 3,072-byte renderer. Recorded model tests prove protocol behavior only. An explicitly enabled remote-host run adds `--live --agent claude --repeats 2`; it uses current host authentication and only a temporary synthetic store. It freezes required/critical and forbidden facts, reports complete sets, per-case coverage, bytes, calls, token availability, sample sizes, p50/p95 and repeated variance. Selective-use recommendations remain disabled until live evidence preserves regressions, loses no critical fact against twenty, returns no forbidden/fabricated fact, and recovers both synonym-only misses. Passing protocol tests cannot substitute for that evidence.
