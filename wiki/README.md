# Docs

This wiki is WongStack's process memory: the reusable knowledge a human or agent should read before acting. Start with the [AI knowledge center](agent-knowledge-center.md) philosophy, then follow the inline links down into whatever you need. Each page stands on its own and breaks down into more detail. How to add without breaking that: [wiki style](wiki-style.md) for a page's shape, [voice](voice.md) for how its sentences read. Building UI? [UX principles](ux-principles.md) for what a screen should *be* before any component is picked.

## Where to find things
