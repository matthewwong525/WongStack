# reply-link

`scripts/reply-link.mjs` opens [a reply link](../../../wiki/development/reply-links.md): its one send reaches the chat, never a secret. `scripts/helper.mjs` keeps [the live line](../../../wiki/stack/live-line.md) to the app.
