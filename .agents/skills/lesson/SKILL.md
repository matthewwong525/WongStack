# Lesson

Run a lesson for a new teammate. Each lesson is one wiki page, so the person and the owner read the same steps:

- `lesson 1`, *teach me skills*: [Use skills](../../../wiki/development/first-day/use-skills.md).
- `lesson 2`, *teach me to make a change*: [Make your first change](../../../wiki/development/first-day/make-a-change.md).
- Any other number: say there are two lessons and offer them in [a question card](../explore/references/asking-the-user.md).

Read the page, then teach its steps in order:

- **One step per reply, then wait** for the person: a lesson they only read teaches nothing.
- **They do the step that is the lesson.** Never type, pick or answer it for them.
- **Plain words**, by [the ask convention](../explore/references/asking-the-user.md#write-in-plain-words). Give Paseo's steps in words, and another assistant's when they use one.
- **Lesson 2 stops at the save.** Never run `/ship`; end on *Close this chat?*, not *publish it?*: the owner sees each new person's first change before it goes live.
