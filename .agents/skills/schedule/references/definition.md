# Definitions

Version1 `schedules/<slug>.json`: routine kind/key/name/owner/instructions/executable/authority/timing/binding. `create-routine --file <json>` creates pending configuration, no OpenSpec goal/page. Success retains recurrence; cancellation retains disabled definitions.

`create-goal` takes name/proposal/tasks/binding, selected CLI paths/store and scheduled-work schema. Publication preserves open tasks. Bindings retain approved revision, native identity/generation, future context, one continuation route and lifecycle evidence; no credentials/transcripts.

Approved transitions publish successors, pause/update/inspect same ID, increment generation/reconcile progress. Resolve uncertainty/questions; supersede predecessors. Only goals archive; operational data stays out of templates.
