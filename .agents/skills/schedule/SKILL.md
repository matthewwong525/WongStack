# /schedule

Prefer scripts/clocks for exports, invoice reminders with payment checks and narrow model calls. Code uses the [change loop](../../../wiki/development/the-change-loop.md), staging trigger and gate. Assistants need judgment or explicit choice.

Read [registration](references/registration.md) and discovered [Paseo](references/paseo.md)/[native](references/native.md) capabilities. Host differs from model; add no runner. [Definitions](references/definition.md) separate routines and goals.

Use `node .claude/skills/schedule/scripts/schedule.mjs`: list/inspect show both kinds/live truth; pause/resume/run/change/cancel target selected bindings. Inspect uncertain mutations. Prepare instructions/destination/absolute time/timezone/uptime/limits; ask to publish/activate in [shared format](../explore/references/asking-the-user.md). [Record delivery](../save/references/schedule-records.md) preserves checks/open goals.

Sessions follow [run](references/run.md), never recursive creation. Calls wait for identified users, never silence. [Migration](references/migration.md) preserves jobs/secrets; teardown is separate.
