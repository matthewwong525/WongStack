# Fresh run

Your first message is the schedule's approved instructions, then a footer. Your computer checked the version and claimed the progress before this chat opened.

Do only those instructions, within *May do*; ask before any other step. When you stop, run the footer's `finish` once: `--progress <json file>` saves what the next run needs; `--done <proof>` ends the schedule, only when it has *Ends when* and that end is met. A run never ends its schedule another way.
