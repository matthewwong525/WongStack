# Paseo

With no `schedules` part, `store` is `paseo`: each schedule is a Paseo chat schedule on this computer, and the store names what Paseo refuses. With a store, an old Paseo job still runs; `pause` and `resume` read it back. To keep it in the store on request: pause it, save it by [registration](registration.md), then delete the Paseo job after `inspect` reads the saved one back. Paseo and this computer must stay on.
