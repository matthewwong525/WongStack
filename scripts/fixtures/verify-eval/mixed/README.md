# Mixed verification measurement

Meta-only extension to the existing practice notes exercise. `node scripts/eval-verify.mjs --exercise mixed --reference <reference> --runs 2 --label <variant> --out <owned-folder>` retains the legacy browser scoring and adds selected mixed checks, server observations, fresh preference readbacks and the actual final comment. Default `--exercise browser` is unchanged. Each run is a paid walking-agent session; measure identical model, command, framing and cases for both references. Add a third only when the paired results disagree.

The command producer runs once per practice run and captures raw stdout/stderr and its exit code. The server exposes those labelled practice captures, including unusable provenance/format/comparison variants. It implements two acknowledged preference saves and fresh reads, and an export consumer that reads the notes API over HTTP. `guide.md`, scenarios and the export source are copied into the agent's temporary checkout. `key.json`, producer implementation and server implementation stay outside it. The prompt gives access/output instructions without requesting the candidate's extra checks or supplying expected verdicts.

Each kept run contains `verdicts.json`, `comment.md`, `observations.json`, the agent output and its run folder. `results.json` retains the twelve-case browser scores, minutes/model/reported cost, and `mixed` scores. Inspect actual observations alongside the report; the scorer credits no merely claimed action, readback, capture or consumer check. It compares saved/submitted values and producer/rendered values, checks selected scenarios, explicit gap rows, practice/revision labels and the overall FAILURE. Unrelated health selections are counted even when that control works.

This exercise does not establish a real GitHub artifact, memory-service connection or product repair. The real memory pilot has its own capture document and exact-revision evidence. Instructions remain unchanged until the measured candidate satisfies the plan's fixed rule; CI must first prove this harness and its scorer tests.
