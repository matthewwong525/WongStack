Why

A private form shows only boxes, so you fill in a card without seeing the page it goes to or what the assistant already typed there. The password page opens on a file drop most people skip. And every form starts from nothing, so you type the same card, email, and address again each time.

What Changes

  1. 1
    A private form opens with a picture of the site's page. The assistant takes one picture of the whole page as the link opens: its own answers typed in, your private boxes still empty. The picture sits first, above the boxes. Tap it to see it full screen, then zoom and drag around it; close goes back to the form. Tapping the picture:

Decisions

  1. asked2026-10-20

    Asked whether saving filled-in details joins the page-picture plan or gets its own → chose the same plan.

  2. asked2026-10-20

    Asked what is saved for next time → chose everyday answers (email, name, address, phone) and private-form details like a card; passwords already save through the password link.

  3. asked2026-10-20

    Asked how saved details are reused → chose ask each time in the chat, and on a yes the assistant fills them itself with no private form.

  4. assumed2026-10-20

    Assumed: the picture is taken by the link's own opener, of the whole page, before anything private is typed, because a picture taken later could show what the person typed.

  5. assumed2026-10-20

    Assumed: the picture opens full screen on a tap with pinch, + and −, and drag, because a whole-page picture is too small to read in place on a phone.

  6. assumed2026-10-20

    Assumed: the password page shows a picture only for a one-site link whose browser page is on that site, because a page on another site would mislead.

  7. assumed2026-10-20

    Assumed: the file drop goes below the add-a-login boxes on every password link, as you asked, keeping its own wording Or drop your password export here.

  8. assumed2026-10-20

    Assumed: Save for next time starts unticked, and saves only once the site accepts, because a refused card is not worth keeping.

  9. assumed2026-10-20

    Assumed: saved details sit in one file next to saved passwords, readable only by this computer's account and not locked with a password of their own, matching saved logins.

  10. assumed2026-10-20

    Assumed: a saved card keeps its security code, because a site asks for it every time and you asked not to type details again.

  11. assumed2026-10-20

    Assumed: the assistant knows a saved card only as card ending 4242, because the chat question has to name it.

  12. assumed2026-10-20

    Assumed: a saved dropdown answer keeps its visible choice too and matches on both, because a site's own value alone picked the wrong month on another site.

  13. assumed2026-10-20
