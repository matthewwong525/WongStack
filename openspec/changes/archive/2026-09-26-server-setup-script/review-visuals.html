↓ A host gets the script

Details

Details

↓ Both paths run the same script

Details

Actor: the script, as root. Action: install what is missing. Result: the same end state on a new server or on a second run.

The script checks itself New 3

Exit 0, or exit non-zero with the name of what is missing.

Details

Actor: the script. Action: look for each tool and the service. Result: the host knows the server is ready, or knows which part failed.

↓

The host adds only its own parts

Its agent, token, or firewall.

Details

Actor: the host. Action: add what is special to it. Result: the script holds no secret and touches no host file.

Today

A hosted service keeps its own build

A cloud-init build in the service's own repo.

Details

Actor: the hosted service. Action: install Node, gh, OpenSpec, Paseo, Claude Code, Codex, OpenCode, agent-browser, and the Paseo service. Result: only that service can make a server.

↓

A fork cannot change its servers

The tool list is not in WongStack, so a fork has nothing to edit.

Details

Actor: a fork owner. Action: none is possible. Result: the fork's servers get the service's tools.

↓

A person with their own server has nothing to run

No WongStack script exists.

Details

Actor: a person with a VPS. Action: install each tool by hand. Result: each server can be different.
