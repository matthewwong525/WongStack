Details

Path B · no change is selected

Inspect changed folders Changed1

Details

This includes untracked plans and committed changes. A branch name is not required to match a change name.

↓ Resolve the evidence

One changed folder

Select that change and proceed.

Details

A unique changed OpenSpec folder identifies the current work even when the branch has another name.

Several changed folders

Stop and ask which change to use.

Details

Do not infer one change from its name or merge several changes automatically.

No changed folder

Try a saved Branch field, then a legacy same-name match. Stop and ask if neither identifies one change.

Details

For a cold ship, a sole unrelated active change is not evidence. Only a unique match can proceed.

How a saved change finds its feature branch after the worktree is clean.

After

Save the selected change Changed1

Record Branch: actual-feature-branch in its proposal before committing.

Details

The proposal stores this as **Branch:** actual-feature-branch. Each save refreshes it from the current feature branch. The change folder and note keep the change name.

↓ Later, in a fresh session

Resume by change name or PR Changed

/continue loads the selected change and finds its saved branch or the PR head.

Details

For older proposals without a Branch field, a same-named branch remains the fallback.

↓ Check the branch

Check out and continue Changed2

Confirm the branch exists, check it out, then resume the change's remaining tasks.

Details

Check available local and remote branches before checkout. A planned change that has not been saved can stay in the current checkout; its first save records the branch.

Today

Save with one shared name

Branch, OpenSpec folder, and note use the same slug.

Details

The proposal does not record a separate feature branch.

↓ Later

Find the same-named branch

A differently named branch has no durable link to the change.

Details

A clean worktree no longer shows which change the branch carried.

  1. The proposal records the real branch at save time, so committing the files does not erase the change-to-branch link.
  2. Resume checks the saved branch before checkout. Older same-name changes still work.
